# Branding and Project Identity

Nuitka Studio's source code and documentation are available under the MIT License. That license does not grant trademark rights or permission to imply official endorsement.

## Allowed

- Forking and modifying the source
- Referring to compatibility with Nuitka Studio
- Stating that a project is based on or derived from Nuitka Studio
- Using screenshots in reviews, tutorials, and documentation

## Please change the branding when

A redistributed fork substantially changes behavior, security, installers, donation destinations, or update channels. In that case, use a different application name and icon so users can distinguish it from releases maintained by John Edward Dela Cruz.

## Do not

- Claim that a modified build is an official release
- Use the maintainer's name to imply endorsement
- Redirect donations while presenting the build as official
- Remove third-party notices or required copyright attribution

This is a project-branding policy and does not claim that any mark is formally registered. Third-party names, including Nuitka, remain the property of their respective owners.
