# Support

## Questions and setup help

Use GitHub Discussions when enabled, or open a support issue using the most appropriate issue template. Include:

- Nuitka Studio version
- Operating system and architecture
- Python version and interpreter path
- Nuitka version output
- Build mode and output format
- Relevant log text copied as text, not only a screenshot

## Bugs

Use the bug-report form and provide a minimal project or reproduction when possible. Remove secrets and personal data before attaching logs.

## Upstream Nuitka problems

A failure inside Nuitka itself may need to be reported to the upstream Nuitka project. First reproduce it using the generated command outside Nuitka Studio. Include `python -m nuitka --version` and the minimal failing project when following upstream reporting instructions.

## Security issues

Do not use normal issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
