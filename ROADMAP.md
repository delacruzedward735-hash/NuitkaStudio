# Roadmap

The roadmap is directional and does not guarantee release dates.

## Near term

- Complete clean-machine Windows installer and uninstall testing
- Expand Linux distribution testing beyond Debian-based systems
- Improve diagnostics for missing compilers and project dependencies
- Add reusable project profiles and safer preset import/export
- Improve accessibility, keyboard navigation, and high-DPI testing

## Medium term

- Optional release workflow generation with checksums
- Additional installer/package backends where maintainable
- Plugin architecture for specialized build presets
- Better build-report parsing and dependency guidance
- Signed release documentation and reproducible release checklist

## Not planned as local behavior

- Pretending a Linux binary is a Windows executable by renaming it
- Unsupported local cross-compilation that produces unreliable artifacts
- Uploading private project source to a third-party service without explicit user action
- Paid API requirements for core compilation features

Ideas should be proposed through a feature request before implementation.
